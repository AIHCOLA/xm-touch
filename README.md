# 小满遥控 (xm-touch)

把手机变成这台 Windows 电脑的**触摸板 + 遥控器**。手机端零安装、零注册、不走外网，全程局域网直连。

- 不用装驱动、不用管理员权限
- 手机只需要一个浏览器（iPhone / 安卓都行）
- 零第三方依赖，只用 Python 标准库 + Win32 API
- 手机看不到电脑画面（这是刻意的：不推流，所以延迟极低、几乎不耗电）

---

## 快速开始

1. 电脑装好 Python 3.8+（安装时勾选 *Add Python to PATH*）
2. 双击 `start.bat`
3. 会弹出一个控制页，上面有**二维码**和**配对码**
4. 手机连上**同一个 WiFi**，扫码即可（或手动输入 `http://电脑IP:8765`）
5. 首次运行时 Windows 防火墙会弹窗，选「**允许访问**」（专用网络）

电脑托盘不用管，命令行窗口关掉就停止服务。

## 手势

| 操作 | 效果 |
|---|---|
| 单指拖动 | 移动光标 |
| 轻点 | 左键单击 |
| 双击 | 双击（打开文件/程序） |
| 长按约 0.4 秒后拖动 | 按住左键拖拽（拖窗口、框选） |
| 双指轻点 | 右键 |
| 双指上下滑 | 滚动页面 / 列表 |
| 点底部「键盘」 | 调出手机输入法，直接往电脑里打字 |

> 强烈建议先把「灵敏度」调到顺手。手机屏幕比鼠标垫小得多，默认 1.6× 适合多数人，手重就调低。

## 底部按钮与快捷键

底部常驻：`Esc` `Enter` `←` `→` `键盘` `更多`

点「更多」里的面板还有：

- **窗口 / 系统**：Alt+Tab 切换窗口、显示桌面、Tab、退格、复制、粘贴、剪切、撤销
- **光标 / 翻阅**：上下左右、PageUp/PageDown、Home/End、Delete、空格 —— 放 PPT 时用这个翻页
- **影音**：播放暂停、上一首/下一首、音量±、静音、重新连接、锁定电脑(Win+L)

## 命令行参数

```bash
python server.py                  # 默认 8765 端口，随机 4 位配对码
python server.py --port 9000      # 换端口（被占用时）
python server.py --pin 1234       # 固定配对码，不用每次看屏幕
python server.py --no-pin         # 关闭配对码（同一 WiFi 里谁都能连，别在公共网络用）
python server.py --no-browser     # 不自动打开控制页
```

## 文件结构

```
xm-touch/
├─ start.bat            双击启动
├─ server.py            服务端：静态页面 + WebSocket + 输入注入
└─ static/
   ├─ index.html        手机端触摸板界面
   └─ control.html      电脑端控制页（二维码 / 状态）
```

## 连不上怎么办

1. **确认同一 WiFi**：手机和电脑要在同一个路由器下，别一个连 5G 一个连光猫的另一个网段
2. **防火墙**：Windows 安全中心 → 防火墙 → 允许应用通过防火墙，勾上 Python（专用）
3. **配对码不对**：关掉手机页面重开，重新扫码（二维码里带配对码）
4. **端口被占用**：说明已经开了一个实例，或者别的程序占了 8765，用 `--port 8766`
5. 手机浏览器建议用系统自带浏览器或 Chrome/Safari，微信内置浏览器可能拦截 WebSocket

## 已知边界

- **只有局域网**。不在同一个 WiFi（比如在公司控家里）需要内网穿透或中转服务器，这个工具不做；那种场景建议直接用 ToDesk / 向日葵的免费版。
- **没有画面回传**。想边看画面边点，得做屏幕推流 + 虚拟显示驱动（驱动需要签名），是另一个量级的工程。
- **游戏不适用**。桌面操作、看视频、翻 PPT 都没问题，但 FPS 游戏请插鼠标。

## 安全提示

同局域网内任何拿到配对码的设备都能操作这台电脑。配对码每次启动随机生成，默认只在本次运行有效；家里用够了，公司/公共 WiFi 建议保持开启，用完就关掉服务。
